# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

BookBot is a small, simple python program which will analyse a .txt document and return the number of words and the count of each character. As well as an optional word search function.

Run the program from a terminal and provide the path to a text file as the first argument.

For example:

python3 main.py /books/frankenstein.txt

An optional second argument can be added to search for a specific word within the text.

For example:

python3 main.py /books/frankenstein.txt monster

This will return the number of occurrences of the word "monster" within the text.

A small number of sample books are availible within the repository, which have been provided by [Project Gutenberg](https://www.gutenberg.org/about/)
